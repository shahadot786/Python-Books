# ⛓️ Blockchain & Web3 Roadmap

Build decentralized applications and understand blockchain technology.

## 🗺️ Learning Path

### 🟢 01-Beginner (0-3 months)
*Focus: Foundations*
- [Blockchain Basics](./01-Beginner/Blockchain-Basics/) - How blockchain works
- [Cryptocurrency](./01-Beginner/Cryptocurrency/) - Bitcoin, Ethereum basics

### 🟡 02-Intermediate (3-6 months)
*Focus: Development*
- [Solidity](./02-Intermediate/Solidity/) - Smart contract language
- [Smart Contracts](./02-Intermediate/Smart-Contracts/) - Building dApps

### 🔴 03-Advanced (6-12 months)
*Focus: Specialization*
- [DeFi](./03-Advanced/DeFi/) - Decentralized Finance
- [NFTs](./03-Advanced/NFTs/) - Non-Fungible Tokens
