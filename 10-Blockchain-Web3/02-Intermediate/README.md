# 🟡 Intermediate Level - Smart Contract Development

Build on the blockchain with Solidity.

## 📂 What You'll Learn

| Topic | Description | Estimated Time |
|-------|-------------|----------------|
| [Solidity](./Solidity/) | Ethereum's smart contract language | 4-6 weeks |
| [Smart Contracts](./Smart-Contracts/) | Building and deploying dApps | 4-6 weeks |

## 🎯 Learning Objectives

By the end of this level, you should be able to:
1. Write and deploy Solidity smart contracts.
2. Use Hardhat or Foundry for development.
3. Interact with contracts using Web3.js or Ethers.js.
4. Test contracts thoroughly.
