# 📝 Solidity

Ethereum's smart contract programming language.

## 🗺️ Learning Roadmap

### 1. Language Basics
- Pragma and contract structure
- Data types (uint, address, bytes)
- Variables and visibility modifiers

### 2. Advanced Data Structures
- Arrays and mappings
- Structs and enums
- Storage vs memory vs calldata

### 3. Contract Patterns
- Inheritance and interfaces
- Libraries and modifiers
- Access control

### 4. Development Environment
- Remix IDE
- Hardhat / Foundry
- OpenZeppelin contracts
