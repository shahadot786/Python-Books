# 🖼️ NFTs (Non-Fungible Tokens)

Create and deploy digital collectibles.

## 🗺️ Learning Roadmap

### 1. NFT Standards
- ERC-721 (single NFTs)
- ERC-1155 (multi-token)
- Metadata and tokenURI

### 2. Storage Solutions
- IPFS and Arweave
- On-chain vs off-chain storage
- Pinning services (Pinata, NFT.Storage)

### 3. Marketplaces
- OpenSea integration
- Royalties and secondary sales
- Listing and trading

### 4. Advanced NFT Use Cases
- Dynamic NFTs
- Soulbound tokens
- Gaming and metaverse
