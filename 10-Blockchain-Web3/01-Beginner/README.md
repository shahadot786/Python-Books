# 🟢 Beginner Level - Blockchain Foundations

Understand how blockchain technology works.

## 📂 What You'll Learn

| Topic | Description | Estimated Time |
|-------|-------------|----------------|
| [Blockchain Basics](./Blockchain-Basics/) | Distributed ledger, consensus, cryptography | 2-3 weeks |
| [Cryptocurrency](./Cryptocurrency/) | Bitcoin, Ethereum, wallets, exchanges | 2-3 weeks |

## 🎯 Learning Objectives

By the end of this level, you should be able to:
1. Explain how blockchain creates trust without intermediaries.
2. Understand proof-of-work vs proof-of-stake.
3. Set up a cryptocurrency wallet.
4. Explain the difference between Bitcoin and Ethereum.
