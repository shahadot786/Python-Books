# 🧰 Blockchain Development Resources

- **[Foundry](https://book.getfoundry.sh/)** - Fast smart contract toolkit
- **[Remix IDE](https://remix.ethereum.org/)** - Browser-based IDE
- **[OpenZeppelin](https://www.openzeppelin.com/)** - Secure contract library
